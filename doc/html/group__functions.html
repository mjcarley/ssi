Join intersection points into intersection curves.

Intersection curves are output as a list of indices in p and individual curves in the list are found using the break points in brks:

for ( i = 0 ; i < nb ; i ++ ) {
for ( j = brks[i] ; j < brks[i+1] ; j ++ ) {
pointer to coordinates on curve is &(c[p[j]*cstr])
}
}
Parameters
bvh1initialised ::ss_bvh_t for first surface;
bvh2initialised ::ss_bvh_t for second surface;
clist of intersection points from ssi_surface_surface_intersection, sorted by ssi_curve_sort_points;
cstrstride in c;
ncnumber of intersection points;
duplist of duplicates from ssi_curve_sort_points;
ndnumber of duplicate points.
pon exit, ordered indices of points on intersection curves;
brksindices in p of breakpoints between curves;
nbon exit, number of breakpoints;
wsworkspace, at least 27 doubles.
Returns
0 on success.
